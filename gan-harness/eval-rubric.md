# Design Evaluation Rubric

Evaluate the UI design against the following criteria. **Pass threshold: 7.5/10**

### Design Quality (weight: 0.35)
- Does it look like a premium, high-end product?
- Is the visual hierarchy clear and effective?
- Are contrast and spacing handled masterfully?
- Does it avoid "AI slop" tropes (unnecessary gradients, tiny tracked eyebrows, repetitive card grids)?

### Originality (weight: 0.30)
- Does it break away from the generic SaaS dashboard template?
- Did the designer make a bold, creative leap in layout, color, or component structure?
- Is it memorable and distinctive?

### Craft (weight: 0.25)
- Are animations and transitions fluid, deliberate, and 60fps?
- Are micro-interactions (hover, active, focus) implemented seamlessly?
- Is typography sharp, with proper line-heights, letter-spacing, and kerning?
- Are the CSS and components cleanly implemented?

### Functionality (weight: 0.10)
- Is the core data still legible?
- Can the user still navigate the application?
- Does the layout remain robust across different screen sizes?
